# Owen-125B — Qwen3.8-Flash-Next on RunPod

Отдельное окружение для Qwen3.8-Flash-Next 125B (MoE), сборка IQ2_XS с abliterated refusal-direction и поддержкой изображений. Сервер запускается только по необходимости; клиент на Mac подключается через SSH-туннель.

> «Uncensored/abliterated» означает ослабление отказов модели, а не гарантию безошибочных или всегда отвечающих результатов. Используйте модель законно и проверяйте ответы, особенно в задачах безопасности.

## Сервер для первого пробного запуска

Рекомендованный RunPod вариант — **RTX 3090, 24 GB VRAM, 125 GB RAM**. На странице цен RunPod он указан по **$0.50/час за GPU**, до платы за диск/хранение и сетевые услуги. Конфигурация не 16 GB VRAM, а мощнее и с большим запасом системной памяти; это полезно для большой MoE-модели. Strata указывает поддержку NVIDIA GPU от 12 GB, а карточка выбранной IQ2_XS-сборки указывает около 35.5 GB RAM для экспертов.

Это ориентир из каталога, не гарантия наличия. Перед созданием pod проверьте в панели:

- GPU именно RTX 3090 (или другой вариант только после отдельной проверки), не дороже $1/ч;
- не менее 64 GB системной RAM (у рекомендованного тарифа 125 GB);
- container disk не менее 120 GB (скрипт использует `/tmp`, а не небольшой persistent `/workspace` volume); для удобства выбирайте 120–150 GB;
- Linux x86_64 с NVIDIA-драйвером, доступом по SSH/TCP и возможностью подключиться по SSH;
- итоговую стоимость диска и хранения. Если цена в checkout превышает лимит — не запускайте pod.

Pod срабатывает как оплачиваемая инфраструктура. В первом варианте скрипт не создаёт RunPod pod автоматически и не удаляет ресурсы: сначала создайте подходящий pod в панели, затем подключитесь по SSH. Не выбирайте persistent/network volume для этой пробы: модель будет скачана на временный container disk заново после остановки/перезапуска. RunPod публикует отдельную ставку на container disk ($0.10/GB/month); уточните фактическое списание в панели до подтверждения. Учитывайте storage отдельно от GPU $/час. Остановка pod обычно прекращает оплату вычислений; удаляйте/останавливайте ресурсы только через панель, проверяя их статус.

## Развёртывание: одна команда после SSH

В панели RunPod создайте Linux pod, откройте его SSH-подключение и выполните:

```bash
git clone https://github.com/GrigoryRumm/Owen-125B.git && cd Owen-125B && bash scripts/deploy.sh
```

Перед запуском модели скрипт проверит ОС, NVIDIA GPU (минимум 12 GB VRAM), RAM (64 GiB) и свободное место (110 GiB). Он скачает зафиксированную ревизию модели IQ2_XS, vision projector и refusal-direction vector с Hugging Face, проверит опубликованные SHA-256, затем установит Strata `v0.2.5` и передаст файлы в документированный Strata setup. Загрузка модели — около 70 GB и может занять время.

**Перед подтверждением экранов Strata прочитайте предлагаемый план загрузки и параметры.** API должен остаться на `127.0.0.1:8080`; не разрешайте публичный/LAN-доступ.

## Подключение Mac через SSH-туннель

На Mac откройте отдельное окно Terminal и используйте SSH-параметры, показанные RunPod (пример-шаблон; подставьте свои значения):

```bash
ssh -N -L 127.0.0.1:8080:127.0.0.1:8080 -o ExitOnForwardFailure=yes USER@HOST -p SSH_PORT
```

Не отключайте это окно, пока клиент использует модель. Не публикуйте порт `8080` в RunPod. При первом подключении проверяйте SSH fingerprint штатным способом; не отключайте проверку host key.

В Cline выберите OpenAI-compatible/OpenAI Compatible и укажите:

- Base URL: `http://127.0.0.1:8080/v1`
- Model ID: точное имя, которое вернул `curl http://127.0.0.1:8080/v1/models` через SSH-туннель
- API key: значение, которое сообщает Strata при запуске; если режим `local` не требует ключа, оставьте поле пустым либо используйте значение, допускаемое Cline. Не вставляйте RunPod API key или Hugging Face token.

Проверьте API:

```bash
curl http://127.0.0.1:8080/v1/models
```

Если Strata в выводе старта указала иной model ID или путь, следуйте фактическому выводу; не используйте старый `localhost:8000` endpoint от другой модели.

## Завершение и контроль расходов

1. Завершите запросы в Cline.
2. Остановите API способом, который показал Strata, или завершите GPU pod из панели RunPod.
3. Убедитесь в RunPod, что pod действительно `Stopped`/`Terminated` — закрытие вкладки и SSH-сессии не гарантирует остановку GPU.
4. Проверьте отдельно сохранённые volumes/storage: остановка вычислений не всегда останавливает оплату хранения.

В первой версии автоматический таймер не используется: он не должен создавать ложную уверенность, что оплачиваемый pod выключен. Не запускайте одновременные pods.

## Что пока не подтверждено

- Установка ещё не прошла end-to-end на реальном RunPod экземпляре. Сборка выбрана по актуальной карточке модели и документации Strata; это не означает, что запуск, изображения и Cline уже проверены на конкретном тарифе.
- Пропускная способность будет зависеть от CPU, локального NVMe и host availability. 24 GB VRAM не означает, что все 125B параметров помещаются в GPU; большая часть экспертов работает из системной памяти/диска.
- После первого запуска нужно проверить текстовый ответ, затем image prompt, память, модельный ID/API и фактическую скорость. Результаты зафиксировать в `PROJECT_STATE.md`.
